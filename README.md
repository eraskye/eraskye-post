# ERASKYE

Full-stack social platform: posts, images, music (Spotify), comments, likes, follows, saved posts, notifications, admin panel.

- **Backend:** Node.js + Express + SQLite (better-sqlite3)
- **Frontend:** Vanilla JS SPA (no build step)
- **Auth:** cookie sessions + bcrypt hashing
- **Uploads:** multer + sharp (auto-compress, safe filenames)
- **Music:** Spotify Web API (search) + official preview/embed only

## Requirements
- Node.js **20+**
- An Apple ID / iPhone Safari (any modern browser also works)
